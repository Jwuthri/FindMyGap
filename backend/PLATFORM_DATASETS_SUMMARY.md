# Platform Datasets - Implementation Summary

## What Was Built

A complete system for managing platform-wide datasets with AI-generated metadata, specifically designed for the `reviews_feedback` table containing customer reviews.

## Key Components

### 1. Database Tables

#### `reviews_feedback` Table
- **Purpose**: Store customer reviews from multiple companies
- **Columns**: id, company, category, rating, text, source, date, author
- **Data**: 186 reviews from 4 companies (Spotify, Notion, Slack, Netflix)

#### `platform_datasets` Table
- **Purpose**: Store comprehensive metadata for platform datasets
- **Stores**: Field descriptions, embedding fields, key fields, use cases, data quality notes
- **Generated by**: LLM agent (GPT-4o-mini)

### 2. Core Functions

#### `ingest_mock_reviews()` - Data Ingestion
```python
from app.workflows.utils.data_ingestion import ingest_mock_reviews

result = ingest_mock_reviews(db_path="backend/memory.db")
# Ingests all mock reviews into reviews_feedback table
```

#### `generate_platform_metadata()` - Metadata Generation
```python
from app.workflows.utils.data_ingestion import generate_platform_metadata
from agno.models.openai import OpenAIChat

model = OpenAIChat(id="gpt-4o-mini", api_key=SETTINGS.OPENAI_API_KEY)
result = await generate_platform_metadata(
    table_name="reviews_feedback",
    db_path="backend/memory.db",
    model=model
)
# Uses LLM to analyze table and generate comprehensive metadata
```

#### `register_platform_dataset()` - Metadata Storage
```python
from app.workflows.utils.schema_manager import register_platform_dataset

success = register_platform_dataset(
    db_path="backend/memory.db",
    table_name="reviews_feedback",
    metadata=metadata_dict
)
# Stores metadata in platform_datasets table
```

#### `get_platform_dataset_metadata()` - Metadata Retrieval
```python
from app.workflows.utils.schema_manager import get_platform_dataset_metadata

metadata = get_platform_dataset_metadata(
    db_path="backend/memory.db",
    table_name="reviews_feedback"
)
# Retrieves and parses stored metadata
```

### 3. Scripts

#### `setup_platform_datasets.py` - Complete Setup
**One-command setup for everything:**
```bash
python backend/scripts/setup_platform_datasets.py
```

**What it does:**
1. Creates `platform_datasets` table
2. Ingests 186 reviews into `reviews_feedback`
3. Generates metadata using GPT-4o-mini
4. Stores metadata in database

#### `view_platform_metadata.py` - View Metadata
```bash
python backend/scripts/view_platform_metadata.py
```
Displays all stored metadata in human-readable format.

#### `regenerate_metadata.py` - Update Metadata
```bash
python backend/scripts/regenerate_metadata.py reviews_feedback
```
Regenerates and updates metadata for a table.

## Use Cases

### 1. Semantic Search
The metadata identifies `text` as the primary field for embeddings:
```python
metadata = get_platform_dataset_metadata(db_path, "reviews_feedback")
text_field = metadata["primary_text_field"]  # "text"
# Use this field for vector embeddings and semantic search
```

### 2. Query Planning
The LLM knows which fields are important:
```python
key_fields = metadata["key_fields"]
# ["id", "company", "rating", "text", "source", "date", "author"]
# Use these for filtering, grouping, and analysis
```

### 3. Field Understanding
Human-readable descriptions for every field:
```python
field_desc = metadata["field_descriptions"]["rating"]
# "User rating for the application on a scale of 1 to 5"
```

### 4. Use Case Discovery
AI-suggested use cases:
```python
use_cases = metadata["estimated_use_cases"]
# ["Sentiment analysis...", "Understanding user preferences...", ...]
```

## Next Steps

To add more platform datasets:

1. Create and populate the table
2. Run `generate_platform_metadata()` on it
3. Store with `register_platform_dataset()`
4. Metadata is now available for queries and semantic search

Example:
```python
# Add new dataset
df.to_sql("new_dataset", conn, if_exists="replace")

# Generate metadata
result = await generate_platform_metadata("new_dataset", db_path, model)

# Store metadata
register_platform_dataset(db_path, "new_dataset", result["metadata"])
```
